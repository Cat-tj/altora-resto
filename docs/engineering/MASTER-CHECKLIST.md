# Master Checklist - Altora Resto

Status dokumen: **DRAF DIPERLUAS (correction loop)**. Daftar requirement granular per
domain dengan ID unik, dipakai sebagai sumber kebenaran untuk `TRACEABILITY-MATRIX.md`.
Semua requirement diberi status siklus hidup: `BELUM DIKERJAKAN` -> `DIKERJAKAN` ->
`SELESAI DEV` -> `DIUJI` -> `LULUS`/`GAGAL`. **Tidak ada requirement di dokumen ini yang
sudah diverifikasi lulus** - semua masih `BELUM DIKERJAKAN` per penulisan dokumen ini
(2026-07-24). Dokumen ini mencerminkan target scope PENUH produk (termasuk model/endpoint
yang belum ada di `prisma/schema/schema.prisma` saat ini - lihat `docs/engineering/DEFECT-LEDGER.md`
untuk kesenjangan yang perlu dikoreksi sebelum sebagian requirement ini bisa mulai dikerjakan).

**Total requirement: 249** (target 200-250).

Format ID: `ALT-{DOMAIN}-{urut 3 digit}`, dimulai ulang dari 001 di tiap domain.

Kolom tabel requirement di bawah:

- **ID**: identitas unik requirement.
- **Nama**: nama singkat requirement.
- **Deskripsi**: penjelasan ringkas cakupan requirement.
- **Domain**: nama domain fungsional.
- **Ketergantungan**: ID requirement lain yang menjadi prasyarat (`-` jika tidak ada).
- **Acceptance Criteria**: kondisi yang harus benar agar requirement dianggap terpenuhi.
- **Model Data**: model Prisma yang relevan (termasuk model yang belum ada di schema saat ini).
- **Endpoint/Command**: endpoint API atau command domain yang mewujudkan requirement.
- **Permission**: kode izin (`izin.kode`) yang mengontrol akses aksi ini.
- **Route UI**: route frontend terkait (`-` jika murni backend/internal).
- **Test Wajib**: jenis pengujian wajib (Unit/Integration/E2E/Security) - boleh lebih dari satu.
- **Status**: seluruh baris `BELUM DIKERJAKAN` di dokumen ini.
- **Bukti**: referensi bukti implementasi/uji (`-` karena belum ada implementasi).
