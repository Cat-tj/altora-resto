# Matriks Traceability - Altora Resto

Status dokumen: **SINKRONISASI PENUH selesai (menutup `ALT-DEF-020`)**. Dokumen ini
DITULIS ULANG SEPENUHNYA untuk menutup celah yang dicatat `ALT-DEF-020`: draf
sebelumnya hanya mencakup ~64 dari 249 requirement (dan sejak itu checklist tumbuh
ke 255 requirement — lihat `ALT-DEF-039`). Setiap satu dari **255 requirement**
`docs/engineering/MASTER-CHECKLIST.md` sekarang punya baris di sini, dikelompokkan
per domain memakai urutan yang sama dengan `MASTER-CHECKLIST.md`.

**Sumber kebenaran per kolom:**

- **Model database** — nama model Prisma diambil dari kolom "Model Data"
  `MASTER-CHECKLIST.md`, lalu **diverifikasi lewat grep langsung** terhadap
  `prisma/schema/schema.prisma` (133 model terdaftar per commit ini). Model yang
  TIDAK ditemukan ditandai eksplisit "TIDAK DITEMUKAN di schema.prisma" — lihat
  bagian "Gap Analysis" di akhir dokumen untuk daftar lengkap dan penjelasan per
  kasus (sebagian adalah nama lama yang sudah diganti ADR, sebagian scaffold awal
  yang memang belum dibangun).
- **Endpoint / Permission / Route UI** — diambil dari kolom yang sama di
  `MASTER-CHECKLIST.md` (sudah disinkronkan dengan `docs/api/API-CONTRACT.md` dan
  `docs/keamanan/PERMISSION-MATRIX.md` oleh masing-masing batch domain — lihat
  `DEFECT-LEDGER.md` untuk detail per batch). Pass ini TIDAK melakukan verifikasi
  string-per-string dari 255 endpoint terhadap `API-CONTRACT.md`/`ROUTE-MAP.md`;
  itu di luar cakupan waktu yang wajar untuk satu batch dokumentasi dan dicatat
  sebagai keterbatasan pass ini di bagian penutup.
- **State machine** — diisi HANYA untuk requirement yang mengacu entitas
  berstatus-mesin nyata di `docs/arsitektur/STATE-MACHINES.md` (Pesanan, Pembayaran,
  Giliran Kasir, Meja, Dapur/Tiket Dapur, Pembelian/PO, Opname, Transfer Stok,
  Koreksi Absensi, Tukar Shift). `-` berarti requirement tidak melibatkan entitas
  stateful atau state machine-nya belum didokumentasikan.
- **Domain event** — diisi HANYA dengan salah satu dari 16 `eventType`
  `DomainOutboxEvent` yang benar-benar didokumentasikan di
  `docs/database/15-platform-infra.md` (batch `ALT-DEF-017`/ADR-016). `-` berarti
  TIDAK ADA event terdaftar untuk requirement ini — ini kadang berarti requirement
  memang tidak butuh event (CRUD murni), dan kadang berarti gap nyata (lihat Gap
  Analysis: requirement yang jelas butuh notifikasi domain event tapi eventType-nya
  belum pernah didokumentasikan, mis. requirement retur/split/reopen pesanan).
- **Unit/Integration/E2E/Security test** — **JUJUR APA ADANYA**: tidak ada test
  runner (vitest/Jest/Playwright) yang wired up di repo ini sampai titik penulisan
  dokumen ini — hanya `packages/test-support/src/architecture/*.test.ts` (22 file)
  yang benar-benar ada dan benar-benar dijalankan (lihat `RELEASE-EVIDENCE.md`).
  File-file itu adalah **test struktur skema** (mencocokkan definisi
  `schema.prisma`), BUKAN unit/integration/e2e/security test aplikasi — kolom
  "Integration test" mencantumkannya sebagai catatan terpisah, bukan pengganti.
  Kolom E2E/Security hanya diisi bila `MASTER-CHECKLIST.md` mewajibkan jenis
  test tsb di kolom "Test Wajib"-nya (`-` jika tidak wajib).
- **Evidence** — merujuk bagian `RELEASE-EVIDENCE.md` yang benar-benar berisi
  output `prisma format`/`validate`/`generate` dan hasil test arsitektur nyata
  untuk batch domain terkait. `-` untuk domain yang belum pernah disentuh
  correction loop.
- **Status** — TIDAK PERNAH `LULUS`/`SELESAI` di dokumen ini (`MASTER-CHECKLIST.md`
  sendiri masih 255/255 baris `BELUM DIKERJAKAN`, diverifikasi ulang pass ini).
  Untuk domain yang sudah disentuh correction loop, status mencerminkan "skema
  database diperbaiki, implementasi fitur belum" (bukan siap produksi). Untuk
  domain yang belum tersentuh, status mencerminkan "scaffold awal belum diaudit".

**Koreksi kolom Ketergantungan `MASTER-CHECKLIST.md` yang dilakukan pass ini:**
lihat `ALT-DEF-041` di `DEFECT-LEDGER.md` — 18 baris punya kolom Ketergantungan
rusak (9 self-reference, 6 dangling-reference ke ID yang tidak pernah ada, 3 di
antaranya sudah pernah didokumentasikan rencana perbaikannya di `ALT-DEF-036`
tapi belum pernah benar-benar diterapkan ke file). Seluruhnya DIPERBAIKI langsung
di `MASTER-CHECKLIST.md` pada pass ini mengikuti preseden yang sudah ditetapkan
14 batch sebelumnya (dokumen ini boleh mengoreksi cross-reference yang jelas
salah selama dicatat sebagai defect).
